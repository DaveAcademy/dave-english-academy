Let's Practice!

Mashqlar
CORE
Presentation Order
  1. Introduce: 'Good morning! My project is about...' / Tanishtirish.
  2. Main part: 2-3 ideas with pictures. / Asosiy qism.
  3. Conclusion: 'In conclusion, ...' / Xulosa.
  4. Questions: answer 2 questions from the class. / Savollarga javob.
  5. Vote: the class chooses the best presentation. / Ovoz berish.
