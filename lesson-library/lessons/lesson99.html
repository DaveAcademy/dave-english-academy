Let's Practice!

Mashqlar
CORE
Build Your Project
  1. Choose a topic: my town, a tradition, a famous person, a hobby, the environment. / Mavzu tanlang.
  2. Plan 3 parts: introduction, main ideas (2-3), conclusion. / 3 qism.
  3. Write key phrases on cards, not full sentences. / Kalit iboralar.
  4. Make 3-4 slides with pictures. / 3-4 slayd.
  5. Practice aloud 3 times — time it. / 3 marta mashq qiling.
  6. Get feedback from your partner. / Fikr oling.
